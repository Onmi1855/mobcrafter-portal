Creator support and access types

Hub can show both directly hosted files and creator-supported release links. Access type should tell users whether the download is free, external, or linked to a support page such as Patreon.

Supported access labels

  • Free: the release is directly available without support gating.
  • Creator supported: the creator offers support links, bonus files, or optional support around a public release.
  • Patreon linked: the main action points to Patreon or an equivalent support platform.
  • External: the primary file is hosted off-site.
  • Free sample plus support: a sample is public while extras live behind the creator support path.

Expectations for creators

Do not hide broken or missing files behind vague support language. If the main file is off-site, use an external URL. If support is optional, keep the direct file action clear so users know what is free and what is extra.

Expectations for users

Creator support links are owned by the creator, not by the Hub. Review off-site terms, pricing, and download instructions before leaving the site.

How the access type changes the download button

Every release page shows a primary action button whose label and destination depend on the access type and the files attached to the release:

  • Free (JSON or schematic hosted here): the button reads Download JSON or Download and serves the file directly from Hub storage. The download counter increases each time.
  • External: the button reads Open External Release and sends the user to the creator’s off-site page. No file is stored on the Hub for that release.
  • Creator supported / Patreon linked: a public file may still download directly, while an additional Support creator button points to the creator’s support page. The support link never replaces a promised free file.
  • Free sample plus support: the public sample downloads normally, and the support path is offered separately for optional extras.

The What’s included list on each release page mirrors the real attached files (for example a MobCrafter unit JSON, a schematic, or a ZIP), so users can see exactly what the download contains before clicking.

Choosing the right access type

  1. If your file is hosted on the Hub and free to grab, choose Free.
  2. If the real file lives on another platform, choose External and provide the external URL so the button links there honestly.
  3. If you host a working file here but also run a support page, choose Creator supported or Patreon linked and add your support URL.
  4. If only part of the release is public, choose Free sample plus support and make the sample genuinely usable on its own.

Frequently asked questions

Does support gating hide the download?

No. A promised free file must remain directly downloadable. Support links are always additional, never a barrier in front of a file described as free.

Can I change the access type later?

Yes. Owners can edit their own release metadata, including access type, support URL, and external URL, from the release page after signing in.

Who is responsible for off-site pricing and terms?

The creator. External and support destinations are governed by the creator’s own platform terms, not by MobCrafter Hub.

Are creator-supported releases still reviewed?

Yes. All public releases follow the same content guidelines regardless of access type.
