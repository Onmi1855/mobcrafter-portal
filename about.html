About

MobCrafter Hub

MobCrafter Hub is the public release catalog for MobCrafter units, schematics, unit packs, creator assets, and linked creator-supported downloads. It keeps the existing static site plus Cloudflare Worker, D1, R2, and Access setup intact while exposing a cleaner public catalog.

Browse Hub Quick Upload Creators

What lives here

The Hub can publish classic MobCrafter JSON releases, schematic-only downloads, mixed schematic plus unit sets, ZIP bundles, worlds, and external release links. Legacy JSON support remains first-class so existing content and older workflows keep working.

What the site does not invent

Creator pages and release cards are built from real submission data. The site shows titles, descriptions, tags, creator names, download counts, support links, and related metadata that creators or moderators actually saved.

How the stack stays the same

The public pages are still static HTML. The same-origin Worker continues to handle metadata, uploads, moderation, and public APIs. D1 stores release metadata, comments, and likes. R2 stores uploaded files and screenshots. Cloudflare Access remains the login gate for authenticated flows.

MobCrafter Hub is intentionally additive: existing public pages, existing APIs, and existing release data remain valid while new Hub metadata and creator surfaces sit on top.
