About MobCrafter Hub

MobCrafter Hub is an independent, community-maintained library for the MobCrafter Minecraft Forge mod. It exists because creators needed a single, searchable place to share their units and builds — rather than scattered Discord attachments and file hosting links.

What the Hub is

MobCrafter is a Minecraft Forge mod that lets you capture block structures and turn them into summonable, animated units. It produces a JSON file for each unit — a simple, portable format that can be shared between players just by copying a file.

Before the Hub, sharing those JSON files meant hoping someone in a Discord server could find your old attachment, or maintaining your own download page. The Hub solves that by giving every unit and build a permanent, discoverable catalog entry with screenshots, in-browser 3D preview, dependency information, and a direct download.

What you can find here

The Hub catalog includes four types of community-made content:

  • MobCrafter Unit JSON — Summonable units that you install in one file copy. Includes in-browser 3D preview for supported releases.
  • Schematics + Unit Sets — Build files (.schem / .litematic) paired with the matching unit JSON, so you can place the structure in your world AND summon it as a unit.
  • Schematic only — Standalone build files for world-builders who want the structure without the summonable unit.
  • ZIP Packs and External releases — Multi-file bundles, creator asset sets, or releases hosted on the creator's own platform, linked from the Hub catalog.

For creators

Publishing a release on the Hub takes a few minutes through Quick Upload. Creators retain ownership of their work — the Hub hosts or links to it, but does not claim rights over creator content.

  • Upload once, edit any time from your creator dashboard.
  • Choose your access model: free, creator-supported, supporter-only, or external-only.
  • Releases go through a moderation queue before becoming publicly visible, keeping the catalog quality consistent.
  • Creators can maintain a public creator page that shows all their published releases.

Community values

The Hub is built on four principles that shape how moderation decisions are made:

  • Honesty — Metadata, descriptions, and access types must accurately represent what a release contains. Misleading users is not acceptable regardless of intent.
  • Attribution — Credit the creators and mods that made your work possible. Do not claim or re-upload others' work without explicit permission.
  • Quality over quantity — Releases should be tested, complete, and useful before being published. The goal is a catalog users can trust, not a high submission count.
  • Community safety — No malware, no deceptive archives, no content designed to harm users or the game environment.

Technical foundation

The Hub is a static site hosted on Cloudflare Pages, backed by a Cloudflare Worker API, a D1 database for release metadata and community data, and an R2 bucket for uploaded files and screenshots. Authentication for creator flows uses Cloudflare Access. The stack was chosen to keep running costs minimal and performance consistent globally without managing servers.
