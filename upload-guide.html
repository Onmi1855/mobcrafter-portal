Quick Upload Guide

Quick Upload now supports metadata-first Hub releases. JSON is still optional for metadata entry but remains the only format that unlocks the Hub 3D preview and legacy summon workflow.

Open Quick Upload AI guidelines

Choose the right metadata

  • Set content type to match what you are actually sharing.
  • Set file availability so the detail page explains whether the release is JSON, schematic, ZIP, both, or external-only.
  • Use access type to make free, creator-supported, Patreon-linked, or external access clear up front.

Files and links

You can upload the classic JSON, attach one extra file through the file-upload route, or publish an external release URL instead of uploading files directly. Support URLs are optional and can point to creator support pages such as Patreon.

Preview and edit mode

JSON remains optional for Hub metadata, but it is still required for the in-browser 3D preview. Existing releases can be reopened in edit mode from the creator dashboard without assuming that every release has JSON.

Only upload content you have the right to distribute. If AI assisted the build or workflow, disclose that in the creation method metadata.
