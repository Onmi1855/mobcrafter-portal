Contact

Contact MobCrafter Hub

Use the routes below to reach the site operator for support, moderation questions, privacy concerns, or to report a problem. Please use the most specific route for your issue so it reaches the right place quickly.

General inquiries and site issues

For general questions about the Site, reports of broken public metadata, moderation concerns, or anything not covered by the more specific routes below, open a public issue on the Hub's GitHub repository:

github.com/Onmi1855/mobcrafter-portal/issues

When opening an issue, please include:

  • The URL of the page or release involved.
  • A clear description of the issue.
  • Any screenshots or error messages that help explain the problem.

Copyright and DMCA takedown requests

If you believe content on MobCrafter Hub infringes your copyright, please review the DMCA page for the required information and the correct contact route for legal notices.

Privacy-related requests

For requests to remove personal data, access information the Site holds about you, or raise a concern under this site's Privacy Policy, open a GitHub issue using the link above and label it clearly as a privacy request.

Creator-specific help

If you are the creator of a release and need to edit metadata, update files, or change publication status, use the creator dashboard after logging in. You can edit any release you own without contacting the operator.

For questions about creator-supported releases, access types, or Patreon linking, see the Creator Support page.

Release-specific help for users

If a release includes a creator support URL, use that route for questions about that specific file, install steps, or creator-side updates. Creator support links are provided and maintained by the creator, not by the Site operator.

MobCrafter Hub is an independent community site. It is not affiliated with Mojang Studios, Microsoft, or any other official Minecraft entity. Please do not contact this site for Mojang or Minecraft support.
