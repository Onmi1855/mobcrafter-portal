MobCrafter

What the mod does

MobCrafter lets you turn Minecraft block builds into summonable units. Hub releases package those units and related creator files so they can be shared publicly.

How to use releases Publish a release

Basic in-game flow

  1. Build a structure with blocks.
  2. Attach a Bone Block as the core or pivot.
  3. Use the Capture Tool on the Bone Block to save the structure as a unit.
  4. Summon the unit in-game.

Where JSON releases go

Downloaded unit JSON files are loaded from config/mob_crafter/units/. In multiplayer, server-side JSON is the source of truth and is synced to clients.

What Hub adds

The Hub keeps JSON compatible while also letting creators publish schematics, ZIP bundles, worlds, creator assets, and external release links around the same creation.
