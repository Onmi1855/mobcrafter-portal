About this creation

An original MobCrafter unit: a dragon built from colorful, crystal-toned blocks in a bright, multi-color palette. This release is a MobCrafter unit JSON file for in-game summoning; it does not include a schematic file. Its vivid coloring suits fantasy showcases, rainbow or crystal-themed builds, and eye-catching centerpiece creatures. This is an original creation.

What’s included

  • MobCrafter JSON unit file

How to use

  1. Download the MobCrafter JSON file.
  2. The filename and JSON id/unitId should match. Example: unit_685d4ee4-a77e-44d0-b0fc-9ab882595ac6.json
  3. Place the JSON into: config/mob_crafter/units/
  4. Load or summon the unit in-game.

Requirements

  • Minecraft Forge 1.20.1 with MobCrafter installed.
  • Install any dependency mods mentioned by the creator before loading the release.
