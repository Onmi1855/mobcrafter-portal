How to use

  1. Download the MobCrafter JSON file.
  2. The filename and JSON id/unitId should match. Example: unit_41ac7376-c918-429d-b231-86d2224833eb.json
  3. Place the JSON into: config/mob_crafter/units/
  4. Load or summon the unit in-game.

Requirements
