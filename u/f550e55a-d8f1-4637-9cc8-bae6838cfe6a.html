About this creation

Noctiseraph, The Fallen Twin-Wing Dragon, is an original dark fantasy dragon creation for MobCrafter. This unit features a fallen celestial dragon silhouette with twin wings, a long flowing tail, dark block tones, and a dramatic airborne presence. The design is suited for night scenes, corrupted skies, boss arenas, ruined temples, and fantasy worlds where a powerful fallen dragon or guardian creature would fit. This release includes a MobCrafter JSON file and a schematic file. The JSON file is intended for MobCrafter unit summoning, while the schematic file can be used as a placed build or display structure in Minecraft. Recommended use: - Boss encounters - Dark fantasy maps - Sky island scenes - Fallen angel or corrupted dragon themes - Cinematic MobCrafter screenshots Check the release page for any dependency mods before downloading.

What’s included

  • MobCrafter JSON unit file
  • SCHEM: Noctiseraph,TheFallenTwin-WingDragon.schem

How to use

  1. Download the MobCrafter JSON file.
  2. The filename and JSON id/unitId should match. Example: unit_f550e55a-d8f1-4637-9cc8-bae6838cfe6a.json
  3. Place the JSON into: config/mob_crafter/units/
  4. Load or summon the unit in-game.
  5. Use the included schematic if you want to rebuild or inspect the structure outside the summon workflow.

Requirements

  • Minecraft Forge 1.20.1 with MobCrafter installed.
  • Install any dependency mods mentioned by the creator before loading the release.
  • A schematic-compatible workflow is required if you want to rebuild the design from the included files.
