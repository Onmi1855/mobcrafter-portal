How to Use Hub Releases

Different Hub releases install differently. JSON remains the most direct MobCrafter format, while schematics, packs, and external releases can include extra steps.

Browse releases MobCrafter basics

MobCrafter JSON

  1. Download the JSON release from the detail page.
  2. Place it in config/mob_crafter/units/.
  3. Install any dependency mods listed by the creator before loading the world or server.
  4. Use MobCrafter items in-game to summon the unit.

Schematics, ZIPs, and worlds

Some releases are not summonable JSON. Schematics and ZIP bundles may contain build files, example worlds, textures, or creator assets. Use the included-file list and the release notes on the detail page before importing them.

External releases

If a release is hosted off-site, the Hub detail page will point to the creator-provided external URL. Supporter-only or creator-supported content may require leaving the Hub to access final downloads.

If a page says a dependency mod is required, install that dependency first. Preview images do not guarantee bundled files or bundled permissions.
