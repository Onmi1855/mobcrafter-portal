AI Guidelines

AI-assisted release guidelines

MobCrafter Hub permits AI-assisted creation workflows. Releases must still be reviewed by a human before publishing, and AI involvement must be disclosed. This page explains exactly what is allowed, what is not, and what you must disclose.

Publish a release Community guidelines

Last updated: June 30, 2026

What AI assistance is permitted

AI tools can legitimately assist with many parts of the MobCrafter creation and publishing workflow:

  • Using AI to suggest block palettes, structure layouts, or unit configurations.
  • Using AI to draft or improve release titles, descriptions, and tags.
  • Using AI-assisted schematic or JSON generation tools, provided the output is verified before upload.
  • Using AI for thumbnail image composition, provided the result is original and does not reproduce copyrighted character art without rights.
  • Using AI for translation or localization of release descriptions.

Required disclosure

Any release where AI played a significant role must be disclosed. Omitting this information is a violation of the community guidelines.

  • Set the Creation method to "AI-assisted" or "AI-generated" in the upload form.
  • Use the Creation note field to describe what AI contributed — for example: "Block layout generated with an AI planning tool, then hand-edited in-game" or "Description drafted with AI assistance."
  • Do not present AI-generated content as entirely hand-crafted without disclosure, even if you edited the result significantly.

Human review is mandatory before publishing

Before publishing any AI-assisted or AI-generated release, you must personally verify:

  • In-game functionality — Does the unit summon and behave correctly in MobCrafter?
  • JSON validity — Is the unit JSON file a valid MobCrafter unit file? Open it in a text editor and confirm the structure before uploading.
  • Dependency accuracy — Are all required mods correctly listed in the release description?
  • File contents — Does the archive contain only what the description says it contains?
  • Screenshot accuracy — Do screenshots or the generated thumbnail actually show the release?

Publishing unreviewed AI output that breaks, crashes, or misleads users is a violation of the community guidelines and may result in the release being removed.

Intellectual property still applies

Using AI to generate a release does not change copyright, trademark, or other intellectual property rules. This is one of the most commonly misunderstood points about AI-generated content:

  • If you prompt an AI with copyrighted reference material (character art, game assets, proprietary designs), the AI output may reproduce protected expression — and that reproduction carries the same IP risk as if you had done it manually.
  • Do not use AI to generate thumbnails or in-game structures that clearly reproduce recognizable copyrighted characters, logos, or branded designs without verified rights.
  • "Generated by AI" is not a legal defense against a copyright infringement claim.
  • You are responsible for ensuring that everything you publish — AI-assisted or not — does not infringe on third-party rights. See the Community Guidelines Section 2 for more on third-party IP.

What is not permitted

  • Publishing raw, unreviewed AI output as a complete, working MobCrafter release.
  • Using AI to reproduce recognizable copyrighted characters, brands, or proprietary assets without verifiable rights.
  • Claiming official starter status for AI-generated content unless it has been independently curated and flagged by moderation.
  • Using AI-generated descriptions to misrepresent what a release actually contains.
  • Mass-generating and uploading low-effort releases with minimal human curation as a way to inflate creator output or catalog volume.

Enforcement

Releases that violate these AI guidelines may be moderated, unpublished, or permanently removed. Creators who repeatedly publish undisclosed AI content or low-quality AI output may have their publishing privileges suspended.

If you are unsure whether your AI-assisted workflow complies with these guidelines, err on the side of disclosing more rather than less, and review the output thoroughly before publishing. For specific questions, see the Contact page.
