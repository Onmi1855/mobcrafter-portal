About MobCrafter Hub (Quick Overview)

MobCrafter is a Minecraft Forge mod that lets you turn block-built creations into a single controllable unit. Build with normal blocks, capture the structure as unit data, then summon it in your world for testing and experimentation.

Basic flow:

  1. Build a structure with blocks.
  2. Attach a Bone Block as the core/pivot.
  3. Use the Capture Tool on the Bone Block to save the structure as a unit.
  4. Summon the unit in-game.

Unit JSON files are loaded from config/mob_crafter/units/. In multiplayer, server-side JSON is used and synced to clients.

Note: units shown in mod screenshots are personal examples and are not bundled with the mod. Hub now accepts community JSON, schematics, packs, and creator-supported releases, but legacy JSON is still the core compatible format.

How to use

  1. Download a release from Hub.
  2. Place the JSON into MobCrafter's unit folder (your modpack must include required dependency mods if used).
  3. Use MobCrafter items in-game to summon the unit.

Creator rules

  • Only upload content you have rights to share.
  • Do not upload copyrighted character models/textures unless you have permission.
  • If your unit uses blocks from other mods, mention them as dependencies.
  • If AI helped generate the creation or workflow, disclose that in the upload metadata.
